# 守仁组Top200日度监控

原GitHub入口保留。按11月终版289个叶子类目限定守仁组，半托12人、全托13人按类目ID对应，人员筛选随经营模式切换。

限流、售罄、广告和价格业务明细按模式、部署区、Goods直接入池，母表仅补充名单信息。限流、售罄全量表中未再出现即为对应异常消失；历史异常保留消失记录。连续检出按连续数据日计算，缺日报重算，同日修订不重复累计。

加价率为售价÷供价−1，低于15%为低档，15%至低于30%为中档，30%及以上为高档。商品按最高有效值互斥归档，SKU记录分别保留档位。供价较上一日同口径上涨独立标记，展示金额和幅度。价格按同SKU、站点、来源比较供价、售价和加价率变化。无有效价格不判断达标；源表跟价状态按同一参考记录对比。广告使用真实统计日期，不将旧广告重复计天数。

刷价计算器只作测算。公式与62站点参数来自复读机已确认版本brush-20260929及brush-sites-20261026-1，固定系数1.07、2%冗余，平台系数只用于费用分支判断；按最终报价复算补偿和临界价，向上取本币金额精度。汇率显示内置或业务参考版本，可单次输入覆盖。

网页已移除跟进和链接登记操作。共享数据由原云端服务提供，管理员可直接上传Excel，加价率表未关联类目的记录仍计算价格，管理员可导出核对；守仁组范围内商品直接分到对应人员，不视为正常。
