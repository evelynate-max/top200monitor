# 守仁组宠物Top200监控

原入口：https://evelynate-max.github.io/top200monitor/ 。团队读取同一共享快照，可在网页上传Excel底表并预览、发布。

监控仅采用守仁组终版289个叶子类目；半托12人、全托13人按类目ID对应。限流、广告使用自身类目，母表只补充名单信息，不拦截业务明细。加价率表通过Goods关联当前及历史类目，未关联的价格仍保留输入和计算结果，供管理员导出核对。

加价率采用用户2026-11-03确认口径：售价=供价×(1+适用税率+加价率)，即加价率=售价÷供价−1−适用税率。税率来自用户原核价SOP与折扣表，按站点和经营模式匹配，不代表当地实时法定税率。采用你在卖家在线系统确认的有据候选中最高建议价策略：罗马尼亚21%、斯洛伐克23%；日本和澳大利亚半托仍为0%，本对本分别按10%。保留候选差异和来源，不冒充法定税率核定。售价、供价使用同币种及同价格来源。详情、导出、总览和每日对比使用同一结果。

低档<15%，中档15%至<30%，高档≥30%。独立Goods按当前筛选范围内最高已确认加价率归档；存在待核记录且无法确认最高档位时单列待核。总览、日度变化、趋势、分布和主表全部按独立Goods去重；SKU、站点及来源记录仅在详情和导出展示。跨部署区只计一个Goods，广告ROAS逐区展示，不平均。

正式部署区只有UDP、EU、GLO。全托售罄表是三区合并来源，没有区域字段；独立按Goods和SKU去重，未提供的区域留空，不虚构或摊分区域。售罄页不应用部署区筛选。限流、售罄按每日完整异常表比较，未出现即消失；缺日报不推断连续异常，同日修订不重复计天数。供价上涨按同商品、SKU、站点、来源和币种比较，保留上期供价、金额和幅度。

刷价计算器仅测算。沿用原7%基础加价，按供价×(1+税率+7%)并列计算；补偿部分沿用1.07系数，平台跟价折扣、2%冗余、费用分支和币种向上取整保留原规则。当前加价率也扣除适用税率，严格低于13%才达标；显示供价×(1+税率+13%)的售价边界。13%是刷价目标，与15%/30%监控分档分开。

对接人和类目下拉支持输入搜索，类目可按ID或名称搜索；只显示本组人员。跟进功能已移除。半托薯铃马不在对应Top200名单的测试数据剔除；守仁终版映射中薯铃马只做半托，规则不影响全托售罄。页面统一指标卡内边距、标题行、数字基线和说明行，并适配窄屏。

店铺身份识别采用source-identity-20261103-1：有店铺ID即可用于监控，不要求先关联统一卖家主体。源表只有卖家／卖家ID时，展示来源身份，不伪造Shop ID；同经营模式同Goods的明细可补充明确店铺。只有缺少可用身份或同Goods店铺ID冲突列入身份待核。PETSOO的260577103326保留为售罄源表卖家ID。浏览器图标同时提供独立文件名的PNG、ICO及站点默认favicon.ico。
